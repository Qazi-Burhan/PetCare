# PetCare

PetCare is a responsive pet-care management app migrated to the Next.js App Router while preserving the existing React Context, reducer, LocalStorage persistence, and CRUD workflows.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Dashboard
- `/pets` — My Pets
- `/pets/add` — Add Pet
- `/pets/[id]` — Pet Details
- `/pets/[id]/edit` — Edit Pet
- `/tasks` — Care Tasks
- `/settings` — Settings
- `/health` — server-rendered health check

## Foundations

- Next.js `16.3.5` App Router
- React Server Components by default for route files
- Existing interactive PetCare UI isolated behind `app/client-app.jsx`
- Tailwind CSS v4 via `@tailwindcss/postcss`
- Design tokens retained in `src/index.css` and exposed in `app/globals.css`
- `.env.example` documents the currently safe public metadata variable
- `.env*` files are ignored; no private credentials are required by this project

The `/health` route fetches `https://jsonplaceholder.typicode.com/todos/1` on the server with a five-minute revalidation window. It renders the response and an explicit error state when the endpoint is unavailable.

## Vercel deployment

Import `https://github.com/Qazi-Burhan/PetCare` into Vercel, keep the framework preset as **Next.js**, and use the default build settings. Vercel will create preview deployments for pushes and pull requests once the repository is connected. No deployment credentials are stored in this repository.

Required submission links:

- Repository: https://github.com/Qazi-Burhan/PetCare
- Preview URL: generated by Vercel after the repository is connected
